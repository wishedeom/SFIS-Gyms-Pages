Final exported area validation passes 32 checks, including actual motor routes,
normal Use, journal pause/resume, physical gate/span/lift traversal and the full
67.1-second Demo. Final map-menu, first-person polish and web combat checks pass.

Browser smoke: verified RTX 3060 / ANGLE D3D11, mobile-quality rendering
(1280x720 at 0.5 scale, shadows off), no CPU throttling, recording off. The
unpopulated entry sample measured 60.1 FPS / 16.7 ms p95 with no runtime errors.
This is a desktop diagnostic, not phone performance or a populated-area budget.
Landscape touch UI and the existing portrait landscape-required gate were checked.
