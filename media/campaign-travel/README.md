# Connected campaign travel [PROTO]

Historical pre-corridor capture. The current gate/corridor tour lives in
`../campaign-gate/`; this older tour records the initial inventory-persistence pass.

24-second arranged live capture, 854 x 480, approximately 0.33 MB.
Normal pickups, motor movement through Crew Access, and ordinary return Use
show the same spent pistol magazine and supplies crossing both ways. Local
positions are arranged to shorten the tour; this is not a full playthrough.

The screenshots inspect the live inventory before travel, in Thousand Courts,
and after returning with a local Court supply. The panel is read-only because
the capture driver temporarily releases the player session to issue ordinary
actor intents. Interactive Control mode supports normal inventory editing.

Existing procedural prototype environments and labels are marked PROTO. No new
imported art was introduced. Existing prototype asset provenance is retained.

Character/inventory persistence lasts for the host session; reload starts fresh.
Loose physical cargo must be put down before transit. Actors and loose world
props rebuild when returning. Durable saves and the holding-house interior/rescue
are not implemented.
