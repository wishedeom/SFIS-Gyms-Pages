# The Ration Engine [PROTO]

Gameplay captures of the standalone cultivation and power-allocation prototype.
The mobile MP4 records a complete autonomous run using ordinary movement and
interaction, including the physical lift and cultivation restoration.

Geometry, signs, crops and layout are AI-assisted code-built PROTO presentation.
Human models retain the source project's existing third-party PROTO provenance.
These captures do not approve any prototype asset for final use.

Spoken AI names Mir, Naya and Rosh are fictional linguistic developments of the
archival Mithra, Anahita and Sraosha over a proposed 3,000-year language span.
They are authored worldbuilding, not a historical linguistic prediction.
