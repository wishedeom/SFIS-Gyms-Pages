# Recommissioning [PROTO]

The mobile MP4 records actual core/procedure recovery, bench fitting, a measured
movement-and-recovery skill trial, and an active powered leap to a real 3 m route.
It uses normal movement, Use and actor capability requests, with no teleports or
direct advancement grants. The alternative Rebreather provides a view-directed
underwater dive jet, verified with actual underwater motion and resource costs.

All new clinic geometry, module blockouts, signs and captions are AI-assisted
code-built PROTO ONLY. Captures and previews derive from that presentation.
Existing human assets retain their prior third-party PROTO provenance in the
source project. No prototype asset has been approved for final use.

AdvancementPROTO is a separate host-session scope: gains survive map visits,
while a site reload starts fresh. Other gyms and story scopes remain isolated.
